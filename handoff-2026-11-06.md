## Rozhodnutí (potvrzená uživatelem)
- Rozložení: 1 hospoda = výhled + karty; 2–3 pruhy; 4 hospody (Chrám Cthulhu) = posuvné pruhy (varianta C).
- Rvačka bez vyhazovače: hosté odcházejí, dokud hráč neťuká na rváče.
- Pivovar pomalý, pivo prodat nebo vložit do vylepšení (dlouhodobá investice).
- Den (8 min, coins) / noc (4 min, příšery platí **kostmi**); kosti mají být vzácné a vylepšení drahá.
- Talismany těžko získatelné, vylepšení donekonečna za kosti.
- Kostnice: za kosti kostňák hodí kostkou → **náhodný stat +0,5 %** (ne výběr).
- Soupeřova hospoda = **jen číselný milník** (týdenní liga s cílem týdne), žádná postava.
- Denní specialitu uživatel ZRUŠIL („k ničemu“) – nevracet. Hudba podle hospody NE (pruhy se posouvají).

## Důležitý kontext
- Uživatel píše česky, chce krátké odpovědi česky, commity česky, po každé hotové věci push do `main` a číslo commitu.
- Pod každou odpovědí sekce „Čeká na tebe / nevyřešeno“. Pracovat bez ptaní, ptát se jen u změn směru hry.
- Texty jen přes `t()` (zdroj česky), měna „coins“. Před velkou vizuální změnou ≥ 3 návrhy na screenshotech.
- Kontroly: `npx tsc --noEmit`, `npm run build`, `npm test`; snímky `node tools/shot.mjs <url> <out.png> [ms] [js]`
  (vite `npx vite --port 5177` na pozadí, Chromium `/opt/pw-browsers/chromium-1243/chrome-linux64/chrome`).
  Vite po přidání nového locale souboru restartovat.
- Ladění v URL: `?coins=N ?away=s ?pubs=1-4 ?ev=gold|frogs|bat|banshee|brawl ?visit=0-4 ?season=xmas|halloween|beerfest
  ?night=0|1 ?talis=1 ?fakeads=1`.
- Push: `git fetch origin main:refs/remotes/origin/main && git rebase origin/main && git push origin HEAD:main`.
- Pravidlo handoffu (doslova, přepisuj dál): Když kontext chatu přejde přes ~50 % (NE dřív), sám založ novou session
  (create_session) s názvem o jedna vyšším (hospoda 53 → 54 → …), source_url https://github.com/BARONisko/hospoda-idle,
  source_revision main, s předávkou včetně tohoto pravidla; předtím vše commitni a pushni. Když create_session nejde, zapiš
  předávku do PREDAVKA.md, pushni do main a dej uživateli hotový prompt. Uživatel může o předávku požádat i sám dřív – pak ji
  udělej hned. Hospoda 6 při 50 % založí hospodu 7, hospoda 7 založí hospodu 8 a tak dál donekonečna.
