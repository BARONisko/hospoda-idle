## Důležitý kontext
- Kontroly: `npx tsc --noEmit`, `npm run build`, `npm test` (~5 min), `npm run sim`, `node tools/tutwalk.mjs`.
  Vite: `npx vite --port 5177 --strictPort` (HMR vypnuté → po změně kódu vite restartovat, jinak snímky ze staré verze!).
  Pomocné skripty v tools/_tmp (gitignore, v nové session nejsou): play.mjs (bot), perf.mjs/prof.mjs (měření, CDP), prest*.mjs.
- Web se aktualizuje ~2 min po pushi (GitHub Actions Pages) + prohlížeč drží stránku až 10 min → uživateli říct
  „zavři stránku úplně a otevři znovu“ a ať zkontroluje verzi v Nastavení.
- Překlady: nové t() do všech 11 locales (json ensure_ascii=False, indent=1, bez sort_keys, newline na konci).
- Push: `git fetch origin main:refs/remotes/origin/main && git rebase origin/main && git push origin HEAD:main`.
- Hra: https://baronisko.github.io/hospoda-idle/
- Pravidlo handoffu (doslova, přepisuj dál): Když kontext chatu přejde přes ~50 % (NE dřív), sám založ novou session
  (create_session) s názvem o jedna vyšším (hospoda 62 → 63 → …), source_url https://github.com/BARONisko/hospoda-idle,
  source_revision main, s předávkou včetně tohoto pravidla; předtím vše commitni a pushni. Když create_session nejde,
  zapiš předávku do PREDAVKA.md, pushni do main a dej uživateli hotový prompt. Uživatel může o předávku požádat i sám
  dřív – pak ji udělej hned. Hospoda 6 při 50 % založí hospodu 7, hospoda 7 založí hospodu 8 a tak dál donekonečna.
